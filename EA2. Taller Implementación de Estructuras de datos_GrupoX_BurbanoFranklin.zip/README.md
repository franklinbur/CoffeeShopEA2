# PROYECTO ACADÉMICO EA2 – ESTRUCTURAS DE DATOS
## Institución Universitaria Digital de Antioquia (IU Digital)
### CoffeeShopEA2 – Sistema de Gestión de Pedidos de una Cafetería

Bienvenido al repositorio del proyecto académico **CoffeeShopEA2**.

El proyecto completo se encuentra organizado en la carpeta `CoffeeShopEA2/`:

```
EA2/
└── CoffeeShopEA2/
    ├── src/             # Código fuente en Java (model, service, view, test)
    ├── bin/             # Clases compiladas (.class)
    ├── docs/            # Documentación académica (informe, justificación, guion)
    └── README.md        # Documentación principal e instrucciones de ejecución
```

### 🚀 Comandos Rápidos de Ejecución (PowerShell)

```powershell
# Ingresar al directorio del proyecto
cd CoffeeShopEA2

# Ejecutar el menú interactivo principal
java -cp bin coffeeshop.Main

# Ejecutar la suite de pruebas automatizada (10/10 PASS)
java -cp bin coffeeshop.test.SistemaPruebas
```
